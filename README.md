# 🚗 Android Vehicle Rental Management System

## 📌 Project Overview

The **Vehicle Rental Management System** is an Android application developed to make vehicle rental operations easier and more convenient. The application allows customers to browse available vehicles, book vehicles, manage their profiles and view their booking history.

It also provides an Admin module to manage vehicles, customers and rental bookings.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **UI Design:** XML
- **Database:** SQLite
- **Development Environment:** Android Studio
- **Build System:** Gradle

## ✨ Features

### 👤 Customer Module
- User Registration and Login
- Browse Available Vehicles
- View Vehicle Details
- Book Vehicles
- Calculate Rental Amount
- View Past Bookings
- Manage Customer Profile
- Booking Reminders and Notifications

### 🔑 Admin Module
- Admin Login
- Admin Dashboard
- Add, Update and Delete Vehicles
- Manage Customer Details
- View Booking Records
- Manage Vehicle Availability
- Admin Profile Management

## 🗄️ Database

The application uses **SQLite** for local data storage.

The database contains three main tables:

1. **Users:** Stores customer and admin details.
2. **Vehicles:** Stores vehicle information, availability and rental prices.
3. **Bookings:** Stores booking dates, rental amount, booking status and payment details.

## 📱 Application Modules

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/monishaarunkumar302-beep/Android-Vehicle-Rental-System.git
   ```

2. Open Android Studio.
3. Select **Open Project** and choose the downloaded project folder.
4. Allow Gradle to sync.
5. Connect an Android device or start an emulator.
6. Click the Run button to launch the application.
